# What the compendium includes / Qué trae el compendio

The compendium contains the **System Reference Document 5.2.1** (5e rules, 2024 revision) in **English**, under the CC-BY-4.0 license.
It is open content: it is **not** the complete rulebook.

El compendio contiene el **System Reference Document 5.2.1** (reglas 5e, revisión 2024) en **inglés**, bajo licencia CC-BY-4.0.
Es contenido abierto: **no** es el libro de reglas completo.

## Included / Incluye

| | |
|---|---|
| **12 classes** with every feature from level 1 to 20 · **12 clases** con todos sus rasgos (1 a 20) | Barbarian, Bard, Cleric, Druid, Fighter, Monk, Paladin, Ranger, Rogue, Sorcerer, Warlock, Wizard |
| **12 subclasses** (one per class) · **12 subclases** (una por clase) | Path of the Berserker, College of Lore, Life Domain, Circle of the Land, Champion, Warrior of the Open Hand, Oath of Devotion, Hunter, Thief, Draconic Sorcery, Fiend Patron, Evoker |
| **9 species** · **9 especies** | Dragonborn, Dwarf, Elf, Gnome, Goliath, Halfling, Human, Orc, Tiefling |
| **17 feats** · **17 dotes** | origin, general, fighting style and epic boon feats |
| **339 spells** (levels 0–9) · **339 conjuros** | with the class lists of the SRD |
| **38 weapons** · **38 armas** | |

## Not included / No incluye

Whatever the SRD 5.2.1 does not publish. For example / Todo lo que el SRD 5.2.1 no publica. Por ejemplo:

- Subclasses beyond the one per class above; species beyond the nine; most feats; backgrounds, armor and general equipment as compendium entries; spells outside the SRD.
- Las subclases además de la de cada clase, las especies además de las nueve, la mayoría de las dotes, los trasfondos, armaduras y equipo como entradas del compendio, y los conjuros que no están en el SRD.
- Some proper names were removed from the SRD (a spell published elsewhere under a personal name appears here under its plain name).
- Four sidebars and the per-class "Features" tables are not stored as data (the features themselves are).
- The SRD PDF cuts the text of *Telekinesis* short; it is copied as published.

This project does **not** include text from the Player's Handbook or any other non-SRD book. / Este proyecto **no** incluye texto del Player's Handbook ni de otros libros fuera del SRD.

## Adding what is missing / Cómo agregar lo que falta

Load your own entries as `.json` files in `compendio/` inside your characters folder, in the same format as the compendium.
`compendium/plantilla-propia.json` is an example to copy. Your entries show up mixed with the SRD ones, marked "(custom)".

Podés cargar tus **entradas propias** como archivos `.json` en la carpeta `compendio/` dentro de tu carpeta de personajes, con el mismo formato.
En `compendium/plantilla-propia.json` hay un ejemplo para copiar. Se marcan como «(propia)».
